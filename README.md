# Boxworld

웹 브라우저에서 바로 즐길 수 있는 3D 멀티플레이 마인크래프트형 블록 월드 앱입니다. (Node.js + Express + WebSocket + Three.js, 외부 CDN 무의존)

## 주요 기능

### 기본 월드 & 멀티플레이
- **실시간 멀티플레이 (기본 최대 5명)**: 3D 블록 아바타, 닉네임 태그, 들고 있는 도구 실시간 표시, 채팅(`T`/`Enter`)
- **닉네임 간편 입장 + 관리자 로그인**: 일반 사용자는 닉네임만으로 입장, 관리자는 로그인 화면에서 비밀번호 인증 가능
- **개인 가방 vs 영구 보관 상자**: 개인 가방은 로그아웃 시 자동 삭제되지만, 상자(`chest`)·화로(`furnace`)·표지판(`sign`)·포털(`portal`)은 서버 `data/`에 영구 보존
- **128×48×128 지하 광물 월드**: RLE 압축 청크 엔진, 지하 동굴, 석탄·철·금·다이아몬드 광맥, 36그루 숲

### 마인크래프트 요소
- **도구 시스템 & 제작대 (`C`)**: 나무 → 돌 → 철 → 다이아몬드 곡괭이·도끼·삽·괭이 업그레이드, 블록별 채굴 속도 및 티어 제한
- **블록 파괴 애니메이션**: 10단계 균열 텍스처 + 3D 파괴 파편 입자
- **나무 벌목 & 묘목**: 나무 밑둥 파괴 시 나무 전체가 쓰러지며 원목·묘목·사과 드롭, 묘목 심기 및 자동 성장
- **화로 블록 (`furnace`)**: 원석 제련·유리·돌·구운 고기 실시간 제작 (영구 보존)
- **동물 & 농사**: 돼지·양·소·닭 AI, 양털 깎기·사냥, 괭이 경작지·밀 씨앗 재배·빵 제작
- **침대 · 문 · 사다리 · 표지판 · TNT 폭탄**
- **낮/밤 시간 주기 & 동적 날씨**: 3D 해·달·별 하늘, 맑음/비/눈 3D 날씨 입자
- **3D 공간 사운드**: Web Audio API 기반 실시간 합성 효과음

### Boxworld 오리지널 요소
- **설계도 투영 (`B`)**: 반투명 3D 가이드 투영, 위치/회전 조절, 완성도(%), 건축물 캡처 저장
- **64×64 픽셀 스킨 에디터 & 공유 스킨 게시판 (`K`)**: 간편 색상 꾸미기 + 마인크래프트 64×64 PNG 호환 픽셀 에디터 + 스킨 공유
- **순간이동 포털 (`portal`)**: 같은 채널 이름의 포털 간 즉시 순간이동
- **점프 패드 (`jumppad`)**: 밟으면 하늘 높이 슈퍼 점프
- **멀티플레이 3D 이모트 (`G`)**: 머리 위 3D 이모트 말풍선
- **실시간 미니맵 & 빠른 워프 (`M`)**: 2D 지형 미니맵, 접속자/포털 표시, 주요 지점 원클릭 워프
- **건축 붓 3×3 (`R`)**: 1클릭 3×3 평면 빠른 건축
- **관리자 패널 (`P`)**: 영역 보호(`Pos1`/`Pos2`), 시간·날씨 제어, 전체 공지, 접속자 강퇴

## 조작법
- **WASD**: 이동 / **Space**: 점프 / **Space×2**: 비행 모드 전환
- **좌클릭 꾹**: 블록 채굴 / 동물 사냥
- **우클릭 / F**: 블록 설치 · 상자/화로/문/침대/표지판/TNT/포털 상호작용 · 경작 · 양털 깎기 · 음식 먹기
- **1~9 / 휠**: 핫바 선택 / **V 또는 F5**: 1인칭 ↔ 3인칭 시점 전환
- **E**: 개인 가방 · **C**: 제작대 · **K**: 스킨 · **B**: 설계도 · **M**: 미니맵 · **G**: 이모트 · **R**: 건축 붓 3×3 · **P**: 관리자 패널 · **T/Enter**: 채팅

## 설치 및 실행
```bash
npm install
cp .env.example .env   # ADMIN_PASSWORD, PORT, MAX_PLAYERS 등 설정
npm start
```

## 하위 경로(`/helloworld`) Nginx 리버스 프록시 예시
```nginx
location = /helloworld { return 301 /helloworld/; }
location /helloworld/ws {
    proxy_pass http://127.0.0.1:5220/ws;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_read_timeout 1h;
}
location /helloworld/ {
    proxy_pass http://127.0.0.1:5220/;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}
```
